# Donia Spa

Wellness & Beaute de Luxe a Tunis — Site bilingue FR/AR avec systeme de reservation et tableau de bord.

## Acces

- **[Réservation](https://local-services-tn.github.io/donia-spa/)** — Page principale avec prise de rendez-vous en ligne
- **[Dashboard](https://local-services-tn.github.io/donia-spa/dashboard)** — Tableau de bord (mot de passe: `donia2026`)

## Stack

React 19 · Vite 8 · Tailwind CSS 4 · Framer Motion · Recharts

## Lancement local

```bash
npm install
npm run dev
```
